# 八字五行排序算法

这是八字五行力量排行数学算法的资料与验算记录。
我利用自己数学专业的知识设计了一套算法来计算八字的五行力量排行：
一、写出八字的五行力量评分，天干一个算10分，地支按照藏干力量占比来分配分数（总分10分），按照木火土金水的顺序写出列向量E_0，写出之后验证五行力量分数和为80
二、给定五行生克泄耗矩阵T，为便于书写，矩阵T在项目资料中以图片形式呈现
三、给定月令季节矩阵S，十二个月的月令季节矩阵同样均已在项目资料中以图片形式呈现
四、最终五行力量向量U=T·S·E_0
