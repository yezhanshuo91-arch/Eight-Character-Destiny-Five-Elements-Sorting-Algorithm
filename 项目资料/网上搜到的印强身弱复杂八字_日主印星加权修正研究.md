# 网上搜到的印强身弱复杂八字：日主与印星加权修正研究

- 研究日期：2026-08-04
- 研究目录：`D:\Academic reseach interests\八字五行力量排行数学算法`
- 网上核心样本：18例，其中印强身弱13例、印旺身强对照5例
- 外部验证：用户提供的印强身弱2例，不参与调参
- 五行顺序：木、火、土、金、水

## 一、研究目的

原扶身占比法为：

```text
D = U日主 / ΣU
I = U印星 / ΣU
F = D + I
F ≥ 40% 判身强，否则判身弱
```

该公式把一单位印星力量完全等同于一单位日主自身力量。在“母慈灭子、土重金埋、水多木漂、木多火塞”等印星过旺命局中，印星未必能全部转化为日主有效力量，因此容易把印强身弱误判为身强。

本研究通过网上公开复杂命例，尝试给日主和印星设置不同权重，同时加入印过旺触发条件，修正该问题。

- 地支根气：子=癸10；丑=己6、辛3、癸1；寅=甲6、丙3、戊1；卯=乙10；辰=戊6、乙3、癸1；巳=丙6、戊3、庚1；午=丁7、己3；未=己6、丁3、乙1；申=庚6、壬3、戊1；酉=辛10；戌=戊6、辛3、丁1；亥=壬7、甲3。

## 七、权重搜索结果

先分别测试两种加权思路：

```text
非归一化：G = D + w·I
归一化：  H = 0.80D + 0.20I
```

网上18例全样本结果：

| 印星权重w | 说明 | 准确率 |
|---:|---|---:|
| 1.00 | 原扶身法 | 33.33% |
| 0.50 | 印星半权 | 明显改善但仍误判大量母慈灭子命例 |
| 0.25 | 印星四分之一权 | 继续改善，但开始漏判部分印旺身强对照 |
| 0.10—0.22 | 低印权区间 | 在专题样本中形成稳定平台 |
| 0.25以上 | 权重过高 | 多个印强身弱案例重新跨过40%门槛 |

```text
公式A：G₁=D+0.20I
```

## 八、修正后的两阶段扶身印比法

定义：

```text
D = U日主 / ΣU
I = U印星 / ΣU
```

第一步，识别“母旺子弱疑似区”：

```text
D ≤ 27%
且 I ≥ D
```

第二步，同时计算两种条件加权分数：

```text
若进入疑似区：
    G₁ = D + 0.20I
    G₂ = 0.80D + 0.20I
否则：
    G₁ = G₂ = D + I

G₁、G₂均 ≥ 40%：身强
G₁、G₂均 < 40%：身弱
两者一强一弱：临界，进入人工复核
```

解释：

- 公式A保留日主100%力量，只把印星折算为20%；公式B把日主与印星归一化为80%和20%。
- 普通命局中印星仍按100%计入，不破坏原扶身逻辑。
- 只有当日主自身不足27%、且印星比日主还强时，才认为存在印不完全转化、母慈灭子的风险，同时观察两种低印权结果。
- 在疑似区内，34%—48%的判强门槛均得到相同的15/18结果；为与原算法保持统一，最终继续采用40%门槛。
- 5折分层验证每一折均可在该稳定区间取得相同结果。
- 当前条件样本中两公式没有出现一强一弱；公式A正确弱例中最高分为38.45%，距离门槛仅1.55个百分点；公式B最高为33.87%，距离门槛6.13个百分点。因此公式B更保守，公式A则更完整地保留日主自身力量。

## 十二、剩余错例与下一步

### P06、P07

两例的D分别达到34.01%和41.19%，没有进入低印权区，但来源仍判母慈灭子。这说明负数U导致分母缩小后，日主占比本身也可能虚高；仅靠D、I无法解决。

### C05

该例D仅14.39%、I达到69.02%，从二维指标看极像土重金埋弱例，但来源判偏旺。它说明同样的土印很多，是否真的埋金还取决于季节燥湿、日主根位和原局组合。

下一步可尝试加入第三个变量：

```text
R = 日主在四个地支中的本气/中气/余气根分数
```

然后把触发条件扩展为：

```text
D低、I高、R低 → 印强身弱
D低、I高、R高 → 可能印旺身强
```

## 十三、阶段结论

测试表明，两个公式都不宜无条件用于全部八字：

```text
公式A：G₁=D+0.20I
公式B：G₂=0.80D+0.20I
```

更合适的是条件触发后并列计算：

```text
若 D≤27% 且 I≥D：
    G₁=D+0.20I
    G₂=0.80D+0.20I
否则：
    G₁=G₂=D+I

两式均≥40%为身强
两式均<40%为身弱
两式分歧则人工复核
```

条件使用时，两种公式在当前数据中都把印强专题准确率从33.33%提高到83.33%，且保持此前两个数据集准确率不变。全局使用时公式A明显优于公式B，因此当前不能说0.8/0.2一定优于1/0.2；更准确的结论是：公式A泛化稍好，公式B对疑似印强身弱给出的弱判安全边际更大。两式并列可以作为第一版“母慈灭子修正项”，但尚不能替代根气位置和燥湿结构。
